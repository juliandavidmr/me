# Controlé Blender con Codex usando IA

En este video muestro cómo conectar Blender 5.1 con Codex utilizando MCP (Model Context Protocol), permitiendo que un agente de IA controle Blender mediante lenguaje natural.

Partimos desde una instalación limpia, configuramos el addon oficial de Blender MCP, registramos el servidor MCP en Codex y finalmente construimos una escena 3D completa paso a paso utilizando únicamente instrucciones en lenguaje natural.

La demostración incluye la creación de una mesa, iluminación, cámara, una copa de vino y varios elementos decorativos, todo controlado desde Codex.

## Herramientas utilizadas

### Blender 5.1+

Software de modelado y renderizado 3D utilizado para toda la escena.

- [Blender](https://www.blender.org/)

### Blender MCP

Servidor MCP oficial desarrollado por Blender para permitir que agentes de IA interactúen con escenas y herramientas dentro de Blender.

- [Blender MCP](https://www.blender.org/lab/mcp-server/)
- [Blender MCP Setup](https://projects.blender.org/lab/blender_mcp/wiki/Setup)

### Codex

Agente de programación de OpenAI utilizado para comunicarse con Blender mediante MCP.

- [Codex](https://openai.com/codex/)

### ChatGPT

Utilizado para planificación, documentación y generación del avatar mostrado en el video.

- [ChatGPT](https://chatgpt.com/)

### ElevenLabs

Utilizado para generar la voz narrada del video.

- [ElevenLabs](https://elevenlabs.io/)

### Wav2Lip

Utilizado para generar la sincronización labial del avatar a partir del audio.

- [Wav2Lip](https://github.com/Rudrabha/Wav2Lip)

## ¿Por qué MCP es interesante?

MCP está transformando la forma en que interactuamos con aplicaciones de escritorio.

En lugar de limitarse a responder texto, los modelos pueden inspeccionar herramientas reales, ejecutar acciones y modificar entornos complejos.

Blender es un buen ejemplo porque permite visualizar claramente cómo un agente interpreta objetivos de alto nivel y los traduce en operaciones concretas dentro de una aplicación profesional.
